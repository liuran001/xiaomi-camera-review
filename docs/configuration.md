# 配置

容器使用 `.env`，源码开发需自行导出环境变量；应用不会自动读取 `.env`。生成配置：`python tools/init_config.py`。已有 `.env` 不会被覆盖，工具也不会输出密码。

| 变量 | 通用部署默认值 | 作用 |
| --- | --- | --- |
| `RECORDINGS_PATH` | 必填绝对路径 | 宿主机录像目录；只读挂载，缺失时启动失败，不会自动创建空目录 |
| `APP_UID` / `APP_GID` | `1000` / `1000` | 容器身份；初始化工具在非 root Linux 下使用当前 UID/GID |
| `BIND_ADDRESS` | `127.0.0.1` | 监听地址；跨设备访问可改为宿主机的内网地址 |
| `HTTP_PORT` | `8090` | 宿主机端口 |
| `APP_PASSWORD` | 每次初始化随机生成 | 独立网页登录密码；可编辑为自己的密码 |
| `SESSION_SECRET` | 每次初始化随机生成 | 会话签名密钥；修改会使已有独立登录失效 |
| `COOKIE_SECURE` | `0` | HTTPS 部署设为 `1`；HTTP 下设为 `1` 会导致无法维持登录 |
| `SOURCE_TZ` | `Asia/Shanghai` | 解析文件名时间；界面时间轴固定北京时间 |
| `STABLE_SECONDS` | `180` | 连续观察文件大小和修改时间不变的最短时长 |
| `COMPLETE_FILE_BYTES` | `0` | 完成文件大小校验，`0` 为关闭；正数要求严格相等 |
| `SCAN_SECONDS` | `45` | 自动扫描间隔，最少 5 秒 |
| `SAMPLE_SECONDS` | `3` | 人物分析抽样间隔，最少 1 秒 |
| `ANALYSIS_CHUNK_SECONDS` | `60` | 可断点分析块长度，限制 1–60 秒 |
| `EMPTY_SCENE_GATE` | `0` | `1` 启用空场景模型跳过策略 |
| `OPENCV_NUM_THREADS` | `1` | OpenCV 推理线程数，限制 1–4 |
| `PREVIEW_THREADS` | `1` | 播放转码线程数，限制 1–4 |

`COMPLETE_FILE_BYTES=134217728` 只适用于确认每个完整文件均为 128 MiB 的摄像头。其他型号或存在不同长度尾段时，应使用默认 `0`，否则合法录像可能一直处于等待状态。稳定窗口需要至少两次扫描；文件保留了旧修改时间也不会立即进入分析。摄像头暂停上传超过稳定窗口后再续传，仍可能被提前视为稳定；大小变化会使旧分析失效。仅凭文件统计信息无法证明上传端已经永久关闭文件。

空场景策略在默认每 3 秒抽样时，比较低分辨率灰度画面，仅在画面差异比较中忽略左上角时钟。每块首帧及至少每 15 秒强制检测；有人后 30 秒保持每次抽样检测。模型收到完整画面，跳过样本不计为已检测无人。修改抽样间隔会影响这些间隔的实际精度。开关不会省去解码和磁盘读取，也可能漏过短暂、微小运动。

容器内 `RECORDINGS_ROOT=/recordings`、`DATA_ROOT=/data`、`MODEL_ROOT=/models` 已由 Compose 配好。源码开发可覆盖这三个变量以及 `FFMPEG`、`FFPROBE` 的可执行文件路径。`DSM_GATEWAY_SECRET_FILE`、`DSM_APP_PREFIX` 仅用于 DSM 网关，不应添加到普通独立部署中。

缓存上限目前为代码常量：定位 MP4 512 MiB，播放 MP4 1.5 GiB；SQLite、JPEG 和当前在写临时文件另计。单个原片或重封装结果超过 512 MiB 时无法建立定位缓存。缩略图数量随录像增加，需另行规划 `data/` 容量。
